# Contributing

Open an issue describing the expected behaviour, Blender version, and whether it occurs in an interactive or background session. Use a disposable scene or synthetic fixture for repeatable tests. Remove private assets, credentials and unrelated application data before sharing evidence.

For implementation changes, link the milestone and include a protocol test or fixture that reproduces the reported case. Read back effects from Blender or the output file. Document licences and attribution when introducing dependencies or third-party material.

See the [roadmap](docs/roadmap.md) and [release process](docs/releases.md) for qualification gates.
